# CodeLens AI

AI-powered GitHub repository analyzer. Submit any public GitHub URL and get an instant architecture breakdown plus natural language Q&A about the codebase.

## Tech Stack
- Java 21 + Spring Boot 3.5
- Spring AI + Groq (Llama 3.3 70B)
- PostgreSQL + pgvector (Supabase)
- Redis (Upstash)
- React (coming soon)
